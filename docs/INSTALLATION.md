# 便携安装与排错

## 第一次打开

1. 将完整 ZIP 解压到本机可写目录，留足模型和运行库所需空间。
2. 双击 `LocalAIWorkspace.exe`。不要只复制 EXE，也不要在 ZIP 内直接运行。
3. 在聊天模型选择器中选择 Qwen3 8B、Gemma 3 27B 或 Llama 3.3 70B。

便携包包含 EXE、运行时和三款模型，不需要安装系统 Python、FFmpeg 或配置 PATH。完成解压后，本地推理无需网络；下载或更新模型需要网络。详细功能见 [新手指南](beginner-guide/index.html)。

## 模型和资源

| 模型 | 量化 | 权重文件大小 | 处理路径 |
| --- | --- | ---: | --- |
| Qwen3 8B | UD-IQ2_XXS | 2.61 GB | CPU 内存映射 |
| Gemma 3 27B | UD-IQ1_S | 6.51 GB + 0.858 GB 视觉组件 | 文字用受限内存映射；图片/视频抽样帧用同一 27B 的 CPU 视觉路径 |
| Llama 3.3 70B | UD-IQ1_S | 15.85 GB | 受保护的分层 CPU 读取 |

27B 目标速度为 4 token/s，70B 为 0.5 token/s；只有在指定硬件、模型哈希和参数下实测后才能报告达标。当前参考开发机是 i5-1235U、16 GiB RAM、Intel UHD 核显，没有可用 NVIDIA CUDA。70B 文件约 14.77 GiB，此外还需 KV 缓存与计算缓冲，完整运行还需足够的 SSD 空间。内存保护可能在余量不足时拒绝启动或中止任务。

当前低内存预设使用最多 4 个推理线程、2048 token 上下文和每轮最多 256 个新 token。8B/27B 按当前可用内存和用户上限计算驻留预算，70B 分层路径另有最多 4 GiB 的驻留上限；默认进程提交上限 12 GiB。运行日志另行记录实际占用与速度。

## 与自行组合部署的区别

常规自部署需自行安装 llama.cpp、Ollama 等运行时，选择模型和量化，配置上下文、线程、显卡卸载和日志。Local AI Workspace 将固定三模型、桌面聊天、进程回收、内存保护和统计日志 ZIP 整合在一起。同机速度对照需要固定权重、后端、上下文、线程与系统负载。

日志 ZIP 包含设备、模型哈希、首字时间、模型就绪时间、token/s、内存和错误类型，不包含提示词、回答、附件、会话数据库或个人配置。多机比较时需固定模型文件、量化、提示内容、输出 token 数和推理参数。

## 常见错误

| 现象 | 处理 |
| --- | --- |
| 缺少 Python 或运行库 | 重新完整解压 ZIP；不要只复制 EXE |
| 模型文件不存在或校验失败 | 重新完整解压或重新下载，核对清单中的大小和 SHA256 |
| 内存保护拒绝启动 | 关闭暂时不用的大型程序，确认系统可用内存和磁盘空间，再重试 |
| 70B 首字或生成很慢 | 查看当前 token/s 和内存余量；分层读取降低驻留需求，但可能增加读盘时间 |
| 图片/视频附件不能识别 | 检查 27B 主权重与匹配的 `mmproj-F16.gguf` 是否齐全；看图模型选择 27B 或留空自动选择；视频仅分析抽样画面，超出上下文预算时需减少附件 |
| 日志导出失败 | 选择一个已存在且可写的保存文件夹；检查目标磁盘空间 |

## 构建与验证

发布脚本从白名单收集 `app/`、运行库和三款模型，不收集会话数据库、用户设置、下载缓存或其他模型。`scripts.build_three_model_package` 在写包前核对配置模型 ID、文件大小和 SHA256；完成后确认 ZIP 中包含三款聊天权重及一个匹配的视觉投影组件，并验证 ZIP CRC。

运行 `scripts.verify_three_model_package` 对新 ZIP 进行独立检查、解压、离线启动、模型短测、日志导出和 EXE 窗口关闭回收验证。速度目标单独使用有较长输出和重复运行的报告判断，不能用启动 smoke test 代替。
